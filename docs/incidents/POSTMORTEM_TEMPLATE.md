## 영향

- **기간**: 탐지 시각 ~ 완화 시각 (KST)
- **사용자 영향**: 영향받은 플랫폼·화면·세션 수(RUM 기준), 실패한 동작
- **지표**: 에러율·크래시 세션·Web Vitals 변화(Sentry/RUM 수치 인용)

## 타임라인

모든 시각은 KST. 알게 된 시각이 아니라 이벤트 발생 시각을 적는다.

| 시각 | 이벤트 |
| --- | --- |
| HH:MM | 장애 시작(배포·변경 시점) |
| HH:MM | 탐지 경로 — Sentry 알림 / RUM 이상 / 사용자 제보 |
| HH:MM | 트리아지 완료 — 영향 범위·심각도 확정 |
| HH:MM | 완화 조치 — 롤백/토글/재배포 |
| HH:MM | 지표 정상 확인 |

## 근본 원인

- **무엇**: 어떤 변경이 무엇을 깼는가(커밋·PR 링크).
- **왜**: 왜 배포 전에 잡히지 않았는가 — 빠진 테스트, lint/typecheck로 못 잡는 종류, 재현 환경 차이(dev/prod, standalone/shell).
- **기여 요인**: 캐시, shared singleton 버전 불일치, env 차이 등 원인을 키운 조건.
